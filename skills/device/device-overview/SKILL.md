# 设备共性

1台设备 → 3 个仿真资产：Unreal BP（mesh 组件 + 槽位，场景载体）、TOML（全部关节的运动学描述——主动 + 被动都声明在 `[[joints]]`，含类型/局部轴/零位矩阵/脉冲标定）、Lua（被动关节的耦合公式 `resolve_passives`，仅在有被动关节时产出）。
BP 永远必须；TOML 对运动设备必须（Solver 无关节链则 BP 只是静态摆设）；纯静止设备（托盘/载具）只要 BP。

编排侧要保的产物咬合契约，断一环则包到了模型不动：

```
TOML（[[joints]] + script_path）
  ↔ BP（StaticMesh 组件名 = 关节名；DynamicType = 场景路由身份 type）
  ↔ Lua resolve_passives（有被动关节才产出）
```

> 产物进了工程之后怎么被驱动（Solver 解算、总线分发）是**工程实现细节**，不在本技能范围——
> 本技能只管：产物对不对、三件之间咬不咬合、工具怎么用。


## 运动学解读原则（编排侧）

- **宁多勿漏**：资料/结构上能合理推出的运动都建 joint，实际用不用由人工在下游定，编排阶段不擅自删减。
- **不参编**：粉末瓶、工装、载具等是**被操作对象**（耗材/定位件），运动来自机构对它们的夹持搬运，自身无自由度——不建 joint、不进 TOML/Lua，编排结论中出现直接剔除。这是"宁多勿漏"的类别性例外（那条针对机构件）。CAP8A 实测：模型把 4 个粉末瓶 + 3 个对心工装报成"径向平移"，全部成了多出件进人审。
- **joint 不看装配层级**：运动学要动的件都建 joint；`origin_matrix_local` 与 `joint_axis` 均为**相对父级**的局部量（不是世界轴）。
- **同名同构取第 1 主动**：同 parent 下同构一组（如 `手指座_A.1~.4`），第 1 个当主动，其余 1:1 镜像从动，Lua `follow` 指向**同组第 1 个**（不是 parent）。
